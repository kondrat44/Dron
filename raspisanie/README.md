# Расписание КузТАГиС

Откройте **index.html** двойным щелчком в Chrome или Edge. Устанавливать программу, запускать сервер или подключать интернет не нужно. При переносе копируйте всю папку, включая app, vendor и data.

Программа работает только с Дорожным отделением (группы -Д и -БС): остальные группы файла не показываются и не меняются. Программа открывается пустой: сначала загрузите Excel-файл недели. Незаконченную работу можно продолжить кнопкой «Продолжить» на стартовом экране. Программа не составляет и не оптимизирует расписание. Старый исходник в Word и исходные Excel не изменены.

## Работа

1. «Загрузить файл» читает XLSX учебной части или таблицу с явными столбцами, а также CSV UTF-8. Импорт заменяет текущую неделю; кнопка «Отменить» возвращает прежнюю.
2. Общий поиск предлагает группы, преподавателей, кабинеты, корпуса, специальности и отделения. Выберите подсказку. Можно сочетать фильтры; дата переключает на один день.
3. Нажмите карточку: исправьте кабинет/преподавателя или выберите обмен с другой карточкой. Каждая подгруппа и каждая из последовательных пар — отдельное занятие. Изменения относительно загруженного файла отмечены синим, конфликты — красным.
4. «Excel» скачивает тот же файл, что был загружен: те же листы, оформление и объединённые ячейки; меняются только исправленные пары. Файл называется «<имя исходного> (изменено).xlsx» и снова загружается в программу. Плоская таблица текущей выборки — в «Настройках».
5. Для печати выберите группу, преподавателя или кабинет и нажмите «Печать / PDF». Используется А4, альбомная ориентация; длинные расписания продолжаются на следующих страницах.
6. Заполните справочник специальностей и отделений, при необходимости добавьте отделения. В настройках исправьте звонки и правило определения корпуса.
7. Скачивайте резервную копию JSON в настройках. Она сохраняет также справочники, оригинал расписания и правки. Копия нужна при переносе на другой компьютер или очистке данных браузера. История отмены хранится только в текущем сеансе (до 40 действий).

## Тестовые данные

- data/sample.json — занятия 10-й недели с исходными координатами ячеек.
- data/sample.js — те же данные для запуска через file:// без fetch и сервера.
- data/test-original-layout.xlsx — точная копия оригинала 10-й недели; проверяет реальную матрицу с объединениями и подгруппами.
- data/test-import.xlsx — та же неделя в нормализованном формате.
- data/import-issues.json — замечания к 10-й неделе; подробности также доступны в программе.
- UNRESOLVED.md — ограничения источников и уточнения.

CSV и нормализованный XLSX используют столбцы: Дата, Пара, Группа, Подгруппа, Дисциплина, Преподаватель, Кабинет, Начало, Конец. Первые семь заголовков обязательны; последние два необязательны. Дата: ГГГГ-ММ-ДД или ДД.ММ.ГГГГ; пустая пара — перед первой; подгруппа пустая/1/2; несколько групп через |; время ЧЧ:ММ. CSV: разделитель «;» или запятая, двойные кавычки для разделителей/переносов внутри поля.

## Структура для разработчика

- app/style.css — сохранённые стили из прежнего приложения; app/viewer.css — дополнения и печать.
- app/model.js — данные, исходный снимок, корпус, звонки, проверка пересечений, обмен.
- app/reader.js — независимые адаптеры матрицы и плоской таблицы/CSV, валидация и отчёт источника. Будущую выгрузку адаптировать здесь.
- app/xlsx-compat.js — чтение XLSX с сохранением объединений и адресов ячеек.
- app/ui.js — просмотр, поиск, справочники, настройки, минимальные правки, локальное хранение.
- app/export.js — выгрузка в исходном виде (Export.original) и плоская таблица (Export.table).
- app/xlsx-patch.js — правка ячеек прямо в исходном .xlsx без пересборки книги.
- vendor — локальные SheetJS 0.18.5 (чтение) и ExcelJS 4.4.0 (модель книги и экспорт), лицензии рядом. Сетевые запросы запрещены политикой CSP в index.html.
- tests/model.cjs — проверки модели и CSV; tests/integration.cjs — браузерные сценарии; tests/prepare.cjs — повторное извлечение тестовой недели и отчёт по шести исходникам.

Для обычной работы Node/Python не нужны. Для проверок разработчика нужен Node; интеграционные проверки используют Playwright и локальный Chrome. В тестах указан путь к runtime текущей среды — на другом компьютере его следует заменить. Итоги проверок: tests/browser-report.json и tests/import-report.json.

## Другой формат расписания

Без доработок загружаются: исходная матрица учебной части (дата «Расписание на ДД.ММ.ГГГГ» в A1, четыре блока групп в B/H/N/T, дисциплина и следующей строкой преподаватель, объединения ячеек сохранены) и нормализованные XLSX/CSV со столбцами, указанными выше. Пустой, повреждённый или неподходящий файл отклоняется с объяснением; текущее расписание сохраняется.

Чтобы адаптировать другой формат, пришлите 2–3 исходных Excel-файла (.xlsx) за разные недели именно в виде выгрузки купленной программы, без ручного переоформления. Нужны примеры с подгруппами, последовательными парами, субботой и занятиями без номера, если они есть. Приложите пояснение обозначений и отдельный файл звонков/справочник групп, если они поменялись. Фото или PDF можно приложить для сверки внешнего вида; для надёжной настройки чтения нужен сам Excel. Если есть только CSV — пришлите исходный CSV и поясните кодировку/разделитель, если они известны.

## GitHub Pages

Готовая папка github-pages и архив github-pages.zip содержат только файлы для размещения, локальные библиотеки с лицензиями и разрешённую встроенную 10-ю неделю. Загрузите **содержимое** папки в корень репозитория. В Settings → Pages выберите публикацию из нужной ветки, папка / (root). Главный файл index.html, все ссылки относительные, сборка не требуется. Проверен запуск на статическом сервере внутри подпапки репозитория.

После загрузки страницы интернет больше не используется для работы с данными. Холодное открытие ссылки GitHub Pages без сети не гарантируется: для полностью автономного запуска скачайте папку/архив и откройте index.html локально. Изменения каждого пользователя остаются в его браузере и не обновляют опубликованную встроенную неделю.
