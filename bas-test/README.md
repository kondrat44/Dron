# БАС Тест

Тренажёр для подготовки к диагностической работе по специальности 25.02.08 «Эксплуатация беспилотных авиационных систем». 84 вопроса: билеты, темы, экзамен на время, марафон, работа над ошибками, избранное и статистика. Работает без интернета.

## 1. Загрузка на GitHub

1. Откройте репозиторий **kondrat44/Dron** на github.com.
2. Нажмите **Add file → Upload files**.
3. Перетащите в окно всю папку **bas-test** целиком (вместе с папкой `icons` внутри). Если браузер не даёт перетащить папку, сначала нажмите **Add file → Create new file**, введите имя `bas-test/README.md`, сохраните, затем зайдите в папку `bas-test` и загрузите остальные файлы туда, а иконки — в `bas-test/icons`.
4. Внизу нажмите **Commit changes**.

В папке должны лежать: `index.html`, `style.css`, `app.js`, `questions.js`, `manifest.webmanifest`, `sw.js`, `make-icons.html`, `README.md` и папка `icons` с файлами `icon.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`.

## 2. GitHub Pages

Если сайт этого репозитория уже открывается по адресу `https://kondrat44.github.io/Dron/`, ничего делать не нужно.

Если нет: **Settings → Pages → Branch: main, папка / (root) → Save**. Через 1–2 минуты сайт заработает.

## 4. Установка на телефон

**Android (Chrome):** откройте ссылку → на главном экране приложения появится кнопка «Установить». Если её нет: меню **⋮ → «Добавить на главный экран»** или **«Установить приложение»**.

**iPhone (Safari):** откройте ссылку именно в Safari → кнопка **«Поделиться»** (квадрат со стрелкой) → **«На экран Домой»** → «Добавить».

После этого БАС Тест открывается с иконки, без адресной строки, и работает без интернета.

## 5. Как исправить или добавить вопрос

1. Откройте файл `questions.js` на GitHub и нажмите карандаш (Edit).
2. Найдите вопрос по тексту и исправьте `text`, `options`, `correct` (номера правильных вариантов, считаются **с нуля**: первый вариант — 0, второй — 1 …) или `explanation`.
3. Новый вопрос добавляйте по образцу соседних, с новым `id`.
4. Сохраните (**Commit changes**).
5. **Обязательно** откройте `sw.js` и поменяйте версию в строке `const CACHE = "bas-test-v2";` на `bas-test-v3` (в следующий раз — `v4` и т. д.). Иначе на телефонах останется старая сохранённая версия.

После обновления закройте приложение на телефоне и откройте снова (иногда нужно дважды), чтобы подтянулась новая версия.

Прогресс хранится только на телефоне пользователя, в памяти браузера.
